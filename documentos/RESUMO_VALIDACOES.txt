🔄 COMO USAR EM 3 PASSOS:

PASSO 1: No HEAD do seu HTML
─────────────────────────────
<link rel="stylesheet" href="/recursos/css/validacoes.css">

PASSO 2: Em cada INPUT do seu formulário
─────────────────────────────────────────
<input type="email" name="email" 
       data-tipo="email" 
       data-obrigatorio="true" 
       required>

PASSO 3: Antes de </body>
─────────────────────────
<script src="/recursos/js/validacoes_form.js"></script>
<script>
  ValidadorFormulario.inicializarFormulario('seuFormulario');
</script>

📞 SUPORTE RÁPIDO:

Problema: "Campos não validam"
→ Verificar F12 > Console por erros
→ Confirmar que data-tipo está correto
→ Confirmar que JS foi inicializado

Problema: "Mensagens expõem BD"
→ Usar retornarErroGenerico() em vez de echo
→ Colocar BD em try-catch
→ Usar error_log() para debug

Problema: "Limite de caracteres não funciona"
→ Adicionar data-tamanho-maximo="250"
→ Verificar data-tipo="comentario"
→ Reinicializar ValidadorFormulario
